# Data

The transcriptomic data used in this project are publicly available from the NCBI Gene Expression Omnibus under accession:

**GSE196335**

The analysis uses paired baseline and 6-month sigmoid-colon RNA-seq gene-count files.

Raw count files are intentionally not duplicated in this repository.

To reproduce the analysis, download the relevant gene-count files from GSE196335 and place them in:

`data/gene_counts/`

The project metadata used for sample alignment is provided in:

`metadata_GSE196335_main.csv`
